## 二、正文（可直接复制发布）

电脑没有麦克风，真的没必要为它单买一个硬件。

我做了个小工具：phone-VibeKey。
开源项目，MIT 协议，代码全公开，零月费，不依赖任何云服务。
手机浏览器打开一个页面，用你平时用的输入法语音说话，文字直接出现在电脑光标处。松手约 2 秒落字，连续说几句也不会重影、不粘连。

它解决的几件具体麻烦：

· 台式机 / 瘦客户机没麦，想语音输入只能先找麦、插线、调设备
· 买 VibeKey 这类专用硬件要花钱、等快递、还占桌面
· 手机语音输入明明很快，但要复制到电脑得切设备、翻聊天记录、再粘贴
· 用 Agent / Vibe Coding 时，一句话说完还得把手挪回电脑按回车

它怎么做到的：

1. PC 端跑一个 Python 小进程，内存几十 MB，托盘里有个图标
2. 托盘扫码配对，手机端就是个网页，加到主屏幕后像 App 一样点开
3. 用微信输入法 / 豆包 / 讯飞 / Gboard 的语音说话，边说边同步到电脑
4. 手机点「回车」，电脑真的敲一次 Enter，直接把任务交给 Agent
5. 还有「清空电脑输入框」、最近 10 条记录可编辑重发、发送失败自动退回输入框不丢字
6. 说话时手机上会显示录音面板，上滑撤回、松手编辑，都是输入法原生能力

最顺手的用法：
手机放在桌上，对着它把需求说完，点一下回车，电脑上的 Agent 就开始跑。人不用坐直，手不用离开杯子。

适用环境（先看这里，别踩坑）：

· Windows 10/11 + Python 3.10+；手机和电脑在同一局域网
· 同一 WiFi、PC 有线 + 手机 WiFi、双路由 NAT、手机开热点给电脑连，这几种都实测可用
· 微信 / QQ / 钉钉 / 飞书 / Word / 浏览器 / VS Code 输入框都正常
· 手机不限 iOS / Android，但输入法必须自带语音功能

不支持，说清楚：

· 手机用 4G/5G、人和电脑不在一张网：没有中继，连不上
· 管理员权限窗口、游戏反作弊、远程桌面、锁屏登录界面：注入不进去
· 公司 / 校园网开了 AP 隔离、访客网络：设备互相不可见
· macOS / Linux 电脑：PC 端目前只做 Windows

隐私这块：

它不录音、不传音频、不存语音，只把文字发到同网段的电脑。识别用的是你手机输入法的语音能力，输入法本身是否把音频上云，那是输入法的事。MIT 开源，没有月费，不依赖任何云服务。

上手 3 步：pc 目录装依赖 → 双击「启动.cmd」→ 托盘显示二维码，手机扫完加到主屏幕。手机连不上就点托盘里的「修复手机连不上（防火墙）」一键放行。
